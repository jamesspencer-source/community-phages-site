Computer and software notes

Bioinformatics sessions introduce command-line basics, sequence files, genome assembly, BLAST, annotation, and figure preparation. Program-specific account setup and campus network instructions are handled directly with the active cohort.

Software used

  • Terminal or command-line shell
  • Sequence read and assembly tools
  • BLAST and related sequence databases
  • Genome visualization and annotation tools
